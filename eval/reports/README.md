- 추론 강도는 medium이다. 1차 실험은 기본값으로 돌렸고 gpt-6-luna가 추론만 하다 한도에 걸린 호출이 27번 중 11번이라 무효로 처리했다.
- "내용까지 맞는 탐지"는 채점기가 잡은 칸의 주장을 사람이 아니라 AI가 읽고 대조한 값이다. 근처 줄의 다른 문제가 걸린 칸을 뺐다.

- 모델을 올려도 탐지는 크게 늘지 않았다. terra는 호출 시간과 흔들림이 줄었다. 비교 기준선은 `benchmarks/control-bench/reports/`에 있다.
